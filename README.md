# daily-reads

Obsidian eklentisi: aralıklı tekrar (SM-2) veya sıralı döngü ile günlük okuma kuyruğu

## Kurulum (BRAT ile)

1. Obsidian'da **BRAT** eklentisini kur (Community plugins → Browse → "BRAT").
2. `Ctrl+P` → **BRAT: Add a beta plugin for testing**.
3. Yapıştır: `yasirbilgic/daily-reads`
4. **Add Plugin**.

Güncelleme: `Ctrl+P` → **BRAT: Check for updates to all beta plugins**.

## Sürüm
`manifest.json` içindeki `version` ile release tag'i eşleşmelidir (şu an: 1.3.0).
